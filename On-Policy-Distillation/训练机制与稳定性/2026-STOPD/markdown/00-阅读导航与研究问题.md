## 最关键的区分

| 场景 | 能用什么 | 需要什么 |
|---|---|---|
| 完整 student rollout，缺少 teacher labels | AIPW / DR | 正且已知的查询概率；query 前冻结预测器 |
| 未生成 student suffix | sequential residual telescope | 观测前缀上的 tail-gradient surrogate；累积 survival probabilities |
| 动作采样噪声 | vOPD baseline | 动作无关的 baseline；正确行为分布 |
| 高维子集偏移 | CBPS / calibration / ARB | 可计算总体特征；结构和 overlap 假设 |
| 预测 nuisance 误差 | orthogonality / DML | 明确 score；分折或过去数据；在线漂移另作分析 |
| 有界 scalar target | TMLE | 对应 likelihood / targeting；不自动给 actor-gradient 保证 |
