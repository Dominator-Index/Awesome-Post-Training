# 05｜找统计方法与 OPD 的结合点：按估计对象整理

**认知：共同问题是昂贵教学信号只看了一部分，怎样仍得到可信、低噪声的更新。**

关键不是名称是否来自 causal inference，而是它修正哪一种误差、需要哪些可见变量、保留哪个训练目标。

## 1. 一张位置表

| 方法 | 核心操作 | OPD 中的对应问题 | 是否自动保持 STOPD 的原期望 |
|---|---|---|---|
| IPW / Horvitz–Thompson | $IY/e$ | 随机少观察 token/chunk | 原文条件下梯度和保持 |
| AIPW / DR | $m+I(Y-m)/e$ | 部分 teacher feedback 缺失 | 可见特征、已知随机概率、完整预测补项时可保持 |
| Sequential DR | 剩余预测 + survival 加权增量残差 | 随机少生成后段 | 需要新序列构造与可微预测；不是一行替换 |
| Control variate / vOPD | 减去零均值项 | token 动作 Monte Carlo 噪声 | action-independent baseline 下总体梯度期望保持 |
| Neyman orthogonal score / loss | nuisance 误差一阶不敏感 | 学到的反馈/观察模型不准 | 是结构条件，不能单独补未生成数据 |
| DML / cross-fitting | 独立学习 nuisance，再估计目标 | 同批过拟合与依赖 | 需要 score 本身正确；在线策略漂移需另分析 |
| TMLE | 沿目标 score 校准预测模型 | 标量均值、成功率、存活长度估计 | 渐近 targeted inference 不等于每批设计无偏梯度 |
| CBPS / balancing | propensity 拟合同时匹配特征矩 | teacher 查询或数据选择后特征偏移 | STOPD 已知概率无需再拟合；再平衡可能改变期望 |
| ARB | 回归 + 平衡后的残差校正 | 高维低预算 teacher 反馈 | 有 outcome 结构/overlap 条件，通常是偏差与方差控制 |
| Hájek / self-normalized IPW | 分子与加权 count 的比值 | 梯度尺度稳定 | 有限样本通常存在 ratio bias |
| clipping / stabilized weighting | 限制极端权重 | 后段大 $1/p$ | clipping 通常引入偏差；需记录取舍 |
| randomized telescoping | 将目标写为可抽样的增量和 | 迭代/rollout 的随机计算预算 | 是 STOPD 已引用的理论背景，不是新加模块就新颖 |

## 2. DR 不等于“所有方法都能像 IPW 一样恢复”

DR、TMLE、orthogonal loss、CBPS、ARB 不是同一个算法的不同名字：有的是 estimator，有的是 score 的性质，有的是权重的学习规则。迁移时应先写

$$
\text{目标 }\mu/G \quad\longrightarrow\quad
\text{观察机制 }I,e\quad\longrightarrow\quad
\text{可见特征 }X\quad\longrightarrow\quad
\text{预测/平衡项}\quad\longrightarrow\quad\text{误差条件}.
$$

如果 $X$ 本身来自未生成的未来，就不能套静态 missing-outcome 公式。这里最自然的两条路线是已有完整 rollout 上的 teacher-query correction，以及生成中可见前缀上的 sequential residual correction。

## 3. 为什么 matching 通常不是首选

STOPD 缺失的不是另外一个可匹配人的结果，而是该轨迹的未来前缀。匹配另一道题、另一段回答，不自动给出同一 latent gradient。传统 matching 的目标和替代假设不能直接搬来。

## 4. 为什么 normalized / clipped IPW 需要单独写清楚

$$
\widehat\mu_H=\frac{\sum I_tY_t/e_t}{\sum I_t/e_t}.
$$

通常渐近有效但不是有限样本精确无偏。STOPD 的 lagged $C_k$ 就是在区分当前随机分母与先前固定分母。

若将权重截为 $1/\max(e_t,\epsilon)$，其单项偏差为

$$
\left(\frac{e_t}{\max(e_t,\epsilon)}-1\right)Y_t.
$$

若在 AIPW 中截 residual correction，偏差对应

$$
\left(1-\frac{e_t}{\max(e_t,\epsilon)}\right)(m_t-Y_t)
$$

（固定完整单位下）。预测较准时偏差可能更小，但这不是原始双重稳健式在已知概率分支下的精确无偏结论。

## 5. 什么是真正可研究的统计问题

1. **效率：**同样 teacher/rollout 预算，梯度 MSE 能否显著降低？
2. **鲁棒性：**廉价反馈模型错时，真实随机校正能否防止系统性错误教学？
3. **分配：**预算应该按原始分歧分配，还是按预测残差的梯度方差分配？
4. **目标：**只要求保留已有 OPD，还是要改成最终数学/代码成功率？后者需要额外 reward 与识别对象，不能靠 IPW/DR 名字得到。

本组编号围绕前三点建立可检验连接。它们可用于 math reasoning 和 code generation，但任务成功率必须通过独立评估验证。
