# 06｜候选研究问题：teacher 预算应该花在教学信号的不可预测部分吗？

> 状态：有数学依据的研究候选；尚未完成系统 novelty 检索；已完成小规模离线诊断，结果有正有负，尚无在线训练。经典 DR 公式本身不是我们提出的创新。

## 1. High-level 认知

**一个教学信号即使幅度很大，只要廉价模型能够准确预测，就不必每次调用昂贵 teacher。真正需要真实 teacher 的，是会让学生更新方向出错的预测残差。**

## 2. 为什么这个 question 有 motivation

STOPD 的原始 IPW 对观测到的整个梯度乘 $1/p_t$。越少覆盖后段，越要放大它的全部贡献，产生噪声。DIAL / selective OPD 常按原始分歧选择监督位置；这种选择不直接区分“能便宜预测的分歧”和“必须真实查询才能知道的分歧”。

于是有一个明确缺口可检查：**固定昂贵查询预算下，能否让 cheap proxy 提供 dense 教学，只用 true teacher 校正不可预测部分，从而接近完整 teacher 更新？**

它不以 raw disagreement、entropy 或插值参数为核心。核心操作只有一个：**残差校正教学**。概率保持正覆盖，使 proxy 错误能被真实 teacher 修正。

## 3. 最关键公式

完整 rollout 的可实现版本：

$$
\boxed{\widehat g^+=\frac1N\sum_t
\operatorname{sg}\left[b_t+\frac{Q_t}{e_t}(r_t-b_t)\right]
\nabla\log\pi_\theta(y_t\mid c_t).}
$$

$Q_t$ 是随机 teacher 查询，$e_t$ 为真实查询概率，$b_t$ 为冻结的廉价反馈预测。$e$ 已知时，任意 $b$ 下对该完整批次的查询期望保持。

相比原始 IPW，方差控制对象从 $r_tv_t$ 变成 $(r_t-b_t)v_t$。因此 question 可精确写成：**同预算时，预测残差是否比原始教学信号更容易估计？**

## 4. 预算分配是同一问题的推论

以独立查询单位 $u$ 为例，$a_u$ 为残差梯度的条件二阶矩，$c_u$ 为查询成本：

$$
a_u=\mathbb E[\|(r_u-b_u)v_u\|^2\mid X_u].
$$

忽略跨单位 covariance，最小化 $\sum_u(1-e_u)a_u/e_u$，满足 $\sum_u e_uc_u\le B_{\rm budget}$，Lagrange 条件给出

$$
\boxed{e_u^*=\min\left\{1,\sqrt{\frac{a_u}{\lambda c_u}}\right\}.}
$$

$\lambda$ 调整总预算。真实 $a_u$ 在查询前未知，必须由过去数据预测；实现设置 $e_{\min}>0$ 并随机抽样，不能直接用 oracle 残差选择。低预算时 query 数少，预测不准可能抵消收益。

这只是独立 query 设计的结论，不能原封不动用作 sequential stop 的最优规则。prefix 生成强制 nested survival；实际 teacher 前缀成本也非独立 token 成本。最初可用整条 response 作单位，避免声称稀疏输出天然节省 transformer 计算。

## 5. 与已做方法的区别及重合

| 已有方向 | 重合 | 候选需要额外证明的点 |
|---|---|---|
| STOPD | 正覆盖与 IPW 补缺失 | residual estimator 能否在同样计算预算显著降低梯度噪声 |
| vOPD | control variate 降方差 | vOPD 针对动作采样；这里预测 teacher feedback，再处理查询缺失 |
| DIAL/TA/TIP | supervision allocation | query 前使用 cheap predictor；未查询位置仍有预测项，真实随机 residual 保持 baseline 目标 |
| BAS-OPD / SR-OPD | 减少昂贵 teacher supervision | 是否已涉及这种 dense proxy + residual correction，需进一步逐项对照 |
| Sequential DR / randomized telescope | 预测加残差校正 | OPD 可微剩余 surrogate 的实际便宜程度与梯度相关性 |
| Counterfactual learning-to-rank KD | DR 与蒸馏已有结合 | 不能声称首次结合 DR 和 distillation；需要明确 LLM on-policy 更新与预算机制的差别 |

查到的 [BAS-OPD](https://arxiv.org/abs/2609.25891)、[SR-OPD](https://arxiv.org/abs/2610.02678) 已研究 teacher budget，因此“少查老师”本身不够新。[2024 counterfactual ranking KD](https://sigir-ecom.github.io/eCom24Papers/paper_10.pdf) 的 Eq.9 也已有预测加逆概率残差式。这是实际重合，不能回避。

## 6. 先验证什么，避免直接大训练

以下是完整验证计划。小规模离线部分已执行，见 [12｜结果与失败案例](12-最小验证实验与结果.md)；其余尚未执行。

1. 冻结 1.5B student 与一个可负担 teacher，在少量数学/代码回答上计算 full teacher baseline。按完整问题/rollout 分训练与评估，训练一个廉价 predictor。
2. 在同一评估集合、相同真实 teacher 查询预算下，比较 IPW、proxy-only、DR；模拟查询可以利用预先保存的 full labels，但必须标为**离线估计器验证，不是实际加速**。
3. 记录梯度均值、MSE、方向余弦、tail variance，以及预测器被故意扰动时的偏差。多次随机查询比较 estimator，不能靠一次 mask 得结论。
4. 若 DR 均值保持且 MSE 更低，再检查真实 response-level teacher 查询的 wall time 与在线 1.5B 短训。
5. math 用可验证答案，code 用函数测试评估最终正确率；控制总 wall time/teacher cost 和训练步数，分别报告，避免 proxy 开销被遗漏。

## 7. Go / no-go 的判据

值得继续：holdout residual 梯度明显比 raw 梯度易估计；teacher 查询确实减少实际开销；proxy 出错时校正仍可靠；同预算在线收益稳定。

应修改方向：只是把全局系数变小；只在同批拟合上表现好；高预算 audit 吃掉收益；少输出 token 没少 teacher forward；与已有 query-correction 工作完全重合。

## 8. 从它走向真正少 rollout

下一步可研究 [04](04-序列DR能否减少STOPD的rollout.md) 的 $U_0+\sum C/\Pi\,\delta$，把 teacher budget 的残差思想迁移到未生成 suffix。但它需要梯度相关的剩余 surrogate，比上述 feedback 模型困难。先验证可实现的缺失反馈问题，会更容易判断统计方法能否带来实际价值。

**这条方向当前解决的是统计与计算效率，尚未解决“老师哪些偏好在语义上值得学习”。** 若要估计教学对最终成功率的作用，必须重新定义任务收益 estimand 与干预，不能用 DR 三个字替代这个问题。

## 9. 首轮实验后的修正

初版 teacher-query DR 在 code 有收益、math 无收益；弱 tail predictor 在 code 上显著增加方差。现在优先研究 **gradient-aware residual prediction / trust calibration**，而非假设任意 proxy 都能降低成本。小样本 calibration 只是探索性证据，必须在新 split 确认。
