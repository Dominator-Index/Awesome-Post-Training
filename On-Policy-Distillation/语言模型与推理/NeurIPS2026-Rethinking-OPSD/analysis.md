# Rethinking On-Policy Self-Distillation for Thinking Models 解读

依据：[本地论文](paper.pdf)，arXiv:2607.05184v1，2026-07-06，31 页。作者：Simran Kaur、Narutatsu Ri、Yinghui He、Liam Fowl、Sanjeev Arora。本文讨论该版本，不以目录命名判断录用状态。

## 1. 这篇文章到底在解决什么问题

**拥有答案或完整解法的 teacher，其局部生成行为未必适合没有这些信息、需要自己探索的 student。将这种行为逐 token 蒸馏给 thinking model，可能损害它原有的长推理能力。**

作者主要揭示和诊断这一失败模式，称为 fork suppression：特权信息可能压低推理分支、重新考虑和自我纠错相关的监督信号。本文没有提出完整解决算法，也没有证明该机制是准确率下降的唯一或主要原因。

这里讨论的是 privileged-context OPSD 在特定 thinking-model 训练设置下的问题，不是断言所有自蒸馏都无效。

## 2. Motivation：为什么老师看答案可能产生问题

Teacher 获得参考解法后，可以较直接地沿已知路径解答；student 没有这部分信息，需要比较不同方案、验证步骤、发现错误后返回。

因此，teacher 的局部低不确定性可能依赖其额外输入。Student 学到了更直接、更短的回答行为，并不意味着它同时获得了在新题上独立找到正确路径的能力。

教学类比是：老师拿着解答，觉得某一步无需重新检查；学生尚未建立相同判断依据，却被训练成也跳过检查。这是对论文结果的直观解释，不是作者已证明的心理或因果机制。

对我们之前“老师可以看答案”的理解，需要补充：**信息优势可以产生有用指导，但指导还需要适合 student 当前的信息条件及推理需求。**

## 3. 背景和已有方法的问题

OPSD 的学生轨迹解决了一个重要问题：teacher 在 student 实际访问的前缀上提供监督。但 teacher 与 student 看到的完整上下文仍然不同。

两者即使共享 $y_{<t}$，teacher 额外看到 $c$，从而可能形成不同的下一步偏好。On-policy 数据并没有消除这种信息条件差异。

既有方法在 instruction 模型、短生成预算或训练时关闭 thinking 的设置中取得收益，不足以证明它们同样适用于对长思考轨迹的监督。本文专门检验这种外推。

## 4. 研究方法总览

这是一篇负面结果与诊断论文。实验沿以下顺序建立论点：

1. 对比 instruction 模型和 thinking 模型接受 OPSD 后的变化。
2. 对比更强 teacher 的普通 OPD 与加入特权信息的 OPD。
3. 对比仅提供最终答案与提供完整参考解法。
4. 改变评估生成预算，观察短预算收益与长预算损失。
5. 对比特权 teacher 本身与不带特权信息的训练后 student。
6. 分析 fork/lock 比例、固定轨迹上的 token 概率比，以及训练后检查与纠错标记密度。

主要训练使用 JSD、4,096 completion token 上限、一轮训练、有效 batch size 64。普通 OPSD 的 teacher 来自初始 student checkpoint，报告的常规训练关闭 teacher 同步。主要数学训练使用 OpenThoughts 15k；关闭 thinking 的对照表使用 30k，不能将两张表当作完全相同设置。

## 5. 数学表达与关键量

### 5.1 上下文显式的蒸馏目标

$$
y\sim\pi_S(\cdot\mid x),\qquad
L=\sum_t D\left(\pi_T(\cdot\mid x,c,y_{<t}),\pi_S(\cdot\mid x,y_{<t})\right).
$$

$x$ 为题目，$c$ 为 teacher 独有信息，$y$ 是 student rollout。普通 OPD 的 $c$ 为空；privileged OPD 的 $c$ 是答案或解法。OPSD 再要求 teacher 来源于 student 自身 checkpoint。

问题集中于 $c$ 如何改变分布，尤其是自我纠错等关键位置。两边共享轨迹，并不意味着它们拥有相同的决策依据。

论文实验使用混合系数 0.5 的 JSD。标准对称 JSD 可以写为：

$$
m_t=\tfrac12(p_t+q_t),\qquad
\operatorname{JSD}(q_t,p_t)
=\tfrac12\operatorname{KL}(q_t\|m_t)+\tfrac12\operatorname{KL}(p_t\|m_t).
$$

这里 $q_t$ 和 $p_t$ 分别为 teacher、student 分布。该式解释所用散度，并非论文提出的新目标；不能将本文当作只验证 reverse-KL OPD 的研究。

### 5.2 Token 诊断信号

$$
a_t^{\mathrm{diag}}
=\log\pi_T(y_t\mid x,c,y_{<t})-\log\pi_S(y_t\mid x,y_{<t}).
$$

正值表示 teacher 比 student 更偏好实际采样 token，负值表示偏好更低。作者用它展示监督方向变化。它是局部概率比诊断，不能直接等同于最终正确率的真实 advantage，也不能当成 JSD 参数梯度的完整表达。

图 5 固定同一 student 轨迹，仅改变 teacher 是否看参考信息。例如一个窗口：

| Token | 无特权信息的 log-ratio | 有特权信息的 log-ratio |
|---|---:|---:|
| But | +0.95 | -1.96 |
| wait | +0.37 | -4.97 |

同样的重新考虑动作，在两个 teacher 条件下得到不同方向的偏好。正确答案轨迹的窗口也存在类似抑制。但这些例子不能证明所有纠错 token 都有益或都会发生反转。

### 5.3 Fork 与 lock

正文用最高候选概率刻画分布集中程度：最大概率低于 0.25 的位置视为 fork，高于 0.65 的位置视为 lock；附录进一步说明候选支持与竞争性筛选。

Fork 表示多个续写方向仍有竞争力，lock 表示局部续写较确定。这是高歧义决策的代理，不是对语义推理分支的精确识别。Entropy 在这里用于讨论探索结构，本文没有提出统一提高或降低 entropy 的训练方法。

复现需要注意：附录 D 还描述了 top-K 归一化熵阈值（低于 0.20 为 lock，高于 0.60 为 fork）和支持集几何分类，未将这些口径与正文概率阈值完全逐一对应；dense 条件的轨迹上限也与 base/sparse 不同。应核对实际代码，而不能将不同诊断定义视为完全相同。

## 6. 作者认为问题如何产生

论文提出的解释链条为：

**特权信息让 teacher 的推理更确定 → 某些重新考虑或探索动作的概率降低 → 蒸馏传递这种局部偏好 → student 的检查、回退和分支行为减少 → 长预算下原本可获得的推理收益受损。**

关键不在于回答短本身。带着参考解法的 teacher 可以又短又准；没有参考解法的 student 则可能只继承了短回答风格，未继承同等性能。

该解释与多个观测一致，但作者明确指出尚未建立完整因果证明。

## 7. 为什么常见解释不充分

- **只归因于训练长度短：**相同 4k 训练上限下，普通 OPD 能改善 student，加入参考解法的 OPD 却下降。因此训练/评估长度差异不是唯一解释，仍可能存在交互作用。
- **只归因于 teacher 不够强：**更大的 teacher 加特权信息也出现退化，说明不是只有同规模 self-teacher 才有问题。
- **认为回答越短越差：**teacher 在获得解法时可缩短回答而保持较高准确率，短预算 student 也可能受益。
- **认为某几个词就是推理能力：**wait、maybe 等只是词汇代理。真正的分支决策也可能由数学符号或普通连接词承担。
- **认为保护词表就已解决问题：**附录的 epistemic-only OPD 与随机等量 token mask 效果接近，并未建立保护某些词的决定性优势。

## 8. 真正的贡献与待解决问题

本文的贡献是界定特权自蒸馏的失效条件，并把关注点从平均蒸馏损失转向 thinking model 的推理分支结构。

它留下的问题是：**怎样利用答案或参考解法提供指导，同时保留 student 在不知道答案时所需要的探索、检查和纠错能力？**

可以进一步研究按状态或分支可靠性选择 teacher 信号、控制特权信息量、用 student 后续成功率检验纠错动作。但这些都是延伸方向，不是本文已经验证的解决办法，也不是自动成立的新颖性主张。

## 9. 实验、消融和证据链

### 9.1 最直接的上下文对照

表 4，Qwen3-1.7B thinking student，三项数学基准平均 avg@16：

| 设置 | 平均正确率 |
|---|---:|
| 原模型 | 37.2% |
| 普通 OPD，Qwen3-8B teacher 不看解法 | 39.2% |
| 同一更强 teacher 看完整解法 | 35.0% |
| 同规模 privileged OPSD | 30.8% |

所有蒸馏配置都使用 4,096 token 训练上限，评估上限为 38,912。37.2% 到 30.8% 是下降 6.4 个百分点，约 17% 相对下降，不是下降 17 个百分点。附录 C 中普通 OPD 相对原模型的均值增益置信区间略跨零；加入 gold demo 相对普通 OPD 的下降区间为 [-0.065, -0.019]，对信息条件的对照证据更明确。

### 9.2 模型和预算范围

OpenThoughts 全解法 OPSD 下，五个 Qwen/OLMo thinking 模型的三基准均值均下降；作者报告四个比较的题目级 bootstrap 区间排除零，OLMo 的小幅变化需谨慎解释。

4k–8k 评估预算时蒸馏可能持平或改善，32k–38k 时收益缩小或反转。完整解法造成的长预算退化比仅提供答案更强。该发现来自具体两类特权输入，不是任意信息量的普遍单调定理。

### 9.3 行为证据

Thinking 模型的中位 fork rate 在无特权与稠密特权条件间约从 0.083 降至 0.035，instruction 模型变化较小。

跨五个模型的 7,200 对评估 rollout 中，每千 token 的验证标记从 1.63 降至 1.35，回退标记从 6.45 降至 6.29，犹豫标记从 3.79 降至 3.62。归一化后仍下降，说明观测不只是输出变短后的机械结果。

### 9.4 补充对照

关闭训练时 thinking、评估时仍开启的 Qwen3-4B 对照基本保持原有均值；在 thinking rollout 上训练则下降。SD-Zero 风格流程中，自我修订训练帮助 thinking 模型，但之后 OPSD 阶段又抵消收益。

指标 avg@16 是每题 16 次采样的平均正确率，不是 16 次里至少答对一次的概率。附录显示一些设置的 avg@16 下降而 pass@16 不降，应分别解读。

## 10. 局限和适用边界

- 论文没有提出修复方法，也没有用明确干预证明 fork suppression 导致全部准确率损失。
- 实验集中于可验证数学推理，不能直接外推所有 agent、持续学习或 instruction 场景。
- 主实验使用具体 JSD recipe、冻结 teacher 和短训练预算，不能代表所有 OPSD 变体。
- AIME/HMMT 各只有 30 题；题目级 bootstrap 不代替多训练随机种子的稳定性评估。
- Marker 密度和候选概率是探索的代理，少说 wait 不一定等于不会纠错，多说 wait 也不保证纠错有效。
- 短预算压缩收益和长预算推理收益存在权衡，需要按使用场景评价。

## 11. 总结：完整故事线

**老师看过解法，能够跳过一些搜索；学生没看过，却通过逐 token 模仿也减少了搜索。实验中，学生较容易继承老师的简短输出，未必继承老师依赖额外信息获得的准确性。**

这就是本文对 OPSD 的核心质疑：特权信息带来的局部生成优势，怎样才能转化为 student 的独立推理能力，而不损伤其原有的探索与自我纠错。

与上一篇 [Teacher-Token-Reliability](../../训练机制与稳定性/NeurIPS2026-Teacher-Token-Reliability/analysis.md) 的联系是：两者都提醒我们不能直接把 teacher 的局部偏好当作对 student 有益的监督；上一篇用分支可行性诊断和位置加权，本文聚焦特权信息对长推理分支与纠错行为的抑制。
